# Tag

A Tag é um rótulo textual de **status ou categoria** — um elemento compacto com cor semântica e, em alguns tipos, ícone. Comunica o estado de um item, como "Rota aberta" ou "Maré alta". É display-only: não é clicável, não filtra e não conta.

> Para contagem numérica use `Badge`. Para filtro interativo use `Chips`.

## Importação

```tsx
import { Tag } from '@useblu/ocean-react';
```

### Importação específica (recomendado para tree-shaking)

```

### Importação de tipos TypeScript

const StatusTag: React.FC<TagProps> = (props) => <Tag {...props} />;
```

## Variantes

A API é uma união discriminada: escolha a `variant` primeiro; o `type` válido depende dela.

### Default (padrão)

Rótulo de status com cor semântica.

```tsx live
<div style={{ display: 'flex', gap: 8, flexWrap: 'wrap' }}>
  <Tag type="positive">Rota aberta</Tag>
  <Tag type="warning">Maré alta</Tag>
  <Tag type="negative">Farol inativo</Tag>
  <Tag type="neutral">Costa Coral</Tag>
  <Tag type="neutral-02">Recife Azul</Tag>
  <Tag type="neutral-03">Ilha Serena</Tag>
  <Tag type="default">Expedição</Tag>
</div>
```

### Highlight

Rótulo com tratamento visual de destaque.

```tsx live
<div style={{ display: 'flex', gap: 8, flexWrap: 'wrap' }}>
  <Tag variant="highlight" type="important">
    Maré favorável
  </Tag>
  <Tag variant="highlight" type="neutral">
    Costa Coral
  </Tag>
</div>
```

## Aparência

`appearance` define o tratamento visual da variante `default`; `highlight` não recebe essa propriedade. `default` mantém a aparência atual. `translucent` usa o token de fundo correspondente ao tipo com 24% de opacidade, texto claro e ícone colorido; existe somente em tamanho `medium` com ícone.

Use `translucent` em superfícies coloridas. **Não use em fundos brancos.**

| `type`          | Token do fundo                      | Texto                         | Ícone                         |
| --------------- | ----------------------------------- | ----------------------------- | ----------------------------- |
| `positive`      | `$color-status-positive-down` a 24% | `$color-interface-light-pure` | `$color-status-positive-up`   |
| `warning`       | `$color-status-warning-down` a 24%  | `$color-interface-light-pure` | `$color-status-warning-up`    |
| `negative`      | `$color-status-negative-down` a 24% | `$color-interface-light-pure` | `$color-status-negative-up`   |
| `complementary` | `$color-complementary-down` a 24%   | `$color-interface-light-pure` | `$color-complementary-up`     |
| `neutral`       | `$color-interface-dark-up` a 24%    | `$color-interface-light-pure` | `$color-interface-light-pure` |
| `neutral-02`    | `$color-brand-primary-up` a 24%     | `$color-interface-dark-deep`  | `$color-brand-primary-down`   |

```tsx
<Tag appearance="translucent" type="positive">
  Rota aberta
</Tag>
```

## Tamanhos

As aparências `default` e `highlight` aceitam os dois tamanhos. A aparência `translucent` existe apenas em `medium` com ícone. O tamanho e a altura da linha vêm só do `size`; o peso segue a tabela abaixo para `default`, e `highlight` usa sempre **Nunito Sans ExtraBold (800)** em texto branco.

| `size`            | Fonte                      | Tamanho / altura da linha | Uso                                                          |
| ----------------- | -------------------------- | ------------------------- | ------------------------------------------------------------ |
| `medium` (padrão) | Nunito Sans SemiBold (600) | 12px / 12px               | Itens de lista, cards, cabeçalhos de detalhe                 |
| `small`           | Nunito Sans Bold (700)     | 8px / 8px                 | Ao lado de um rótulo, quando a pílula precisa ficar discreta |

```tsx live
<div style={{ display: 'flex', gap: 8, alignItems: 'center' }}>
  <Tag type="warning">Medium</Tag>
  <Tag variant="highlight" type="neutral">
    Medium
  </Tag>
  <Tag type="warning" size="small">
    Small
  </Tag>
  <Tag variant="highlight" type="neutral" size="small">
    Small
  </Tag>
</div>
```

## Cores

| Variante / tipo         | Fundo                                   | Texto                         |
| ----------------------- | --------------------------------------- | ----------------------------- |
| `highlight` `important` | `$color-highlight-pure` (coral)         | `$color-interface-light-pure` |
| `highlight` `neutral`   | `$color-brand-primary-down` (`#5872F5`) | `$color-interface-light-pure` |

## Ícones

Os tipos `positive`, `warning` e `negative` recebem ícone padrão. `icon` substitui o padrão; `setIconOff` remove o ícone por completo.

```tsx live
<div style={{ display: 'flex', gap: 8 }}>
  <Tag type="positive">Com ícone padrão</Tag>
  <Tag type="positive" setIconOff>
    Sem ícone
  </Tag>
</div>
```

## API

### Props

| Prop         | Tipo                                                                                                                                               | Padrão      | Descrição                                          |
| ------------ | -------------------------------------------------------------------------------------------------------------------------------------------------- | ----------- | -------------------------------------------------- |
| `variant`    | `'default' \| 'highlight'`                                                                                                                         | `'default'` | Variante visual — discrimina os `type` válidos     |
| `appearance` | `'default' \| 'translucent'`                                                                                                                       | `'default'` | Aparência visual; translucent exige medium e ícone |
| `type`       | default: `'positive' \| 'warning' \| 'negative' \| 'neutral' \| 'neutral-02' \| 'neutral-03' \| 'default'` · highlight: `'important' \| 'neutral'` | `'default'` | Tipo semântico                                     |
| `size`       | `'small' \| 'medium'`                                                                                                                              | `'medium'`  | Tamanho — define a tipografia                      |
| `icon`       | `React.ReactElement`                                                                                                                               | -           | Ícone custom (substitui o padrão do `type`)        |
| `setIconOff` | `boolean`                                                                                                                                          | `false`     | Remove o ícone, inclusive o padrão                 |
| `children`   | `React.ReactNode`                                                                                                                                  | -           | Texto da Tag                                       |
| `className`  | `string`                                                                                                                                           | -           | Classes CSS adicionais                             |

## Melhores práticas

### ✅ Faça

- Case o `type` ao significado: `positive` para concluído, `warning` para atenção, `negative` para problema
- Use `highlight` para dar ênfase visual a um rótulo
- Use o mesmo `size` para as Tags que aparecem na mesma linha

### ❌ Não faça

- Não use `type="important"` com `variant="default"` — só existe em `highlight`
- Não use a Tag como botão ou filtro
- Não use a Tag para contagem numérica

| Classe                         | Descrição                                            |
| ------------------------------ | ---------------------------------------------------- |
| `.ods-tag`                     | Classe base                                          |
| `.ods-tag--medium` / `--small` | Tamanho — carrega a tipografia                       |

| `.ods-tag--{type}`             | Cor da variante default                              |
| `.ods-tag--highlight__{type}`  | Cor da variante highlight (`important` ou `neutral`) |
| `.ods-tag--translucent`        | Aparência translúcida combinada com o tipo           |
| `.ods-tag__icon`               | Slot do ícone                                        |
| `.ods-tag__content`            | Texto                                                |

## Histórico

- **Padronização de tamanho e peso:** a variante `highlight` deixou de ter tipografia própria (10px ExtraBold) e passou a seguir o `size`. A mudança é visual e alcança todas as telas que já usam a Tag. O fundo da `highlight neutral` segue `brandPrimaryDown`.
