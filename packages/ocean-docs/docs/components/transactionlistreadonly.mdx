# TransactionListReadOnly

Linha de transação **só de leitura**: conteúdo à esquerda e valor à direita, sem interação. Faz parte da família Transaction List (Read Only, Action, Selectable, Expandable e os itens filhos), que substitui o `TransactionListItem`.

Figma: [Transaction List Read Only](https://www.figma.com/design/PgLv9k22CHHZZ867HwN65y/%F0%9F%8C%8A-Ocean-DS-Core?node-id=26559-4449).

## Importação

```tsx
import { TransactionListReadOnly } from '@useblu/ocean-react';
```

```tsx
import type { TransactionListReadOnlyProps } from '@useblu/ocean-react';
```

```tsx live

```

## Tamanhos (contentSize e amountSize)

O tamanho do texto e o tamanho do valor são escolhidos **separadamente**. `md` é o padrão; `sm` é a escala compacta (a mesma dos itens filhos). A tag do valor acompanha o `amountSize` (`md` → Medium, `sm` → Small).

```tsx live
<List>
  <TransactionListReadOnly
    title="Title"
    description="md / md"
    amount="R$ 0,00"
  />
  <TransactionListReadOnly
    title="Title"
    description="sm / md"
    amount="R$ 0,00"
    contentSize="sm"
  />
  <TransactionListReadOnly
    title="Title"
    description="md / sm"
    amount="R$ 0,00"
    amountSize="sm"
  />
</List>
```

## Tipos de valor (amountType)

```tsx live
<List>
  <TransactionListReadOnly title="Default" amount="R$ 100,00" />
  <TransactionListReadOnly
    title="Positive"
    amount="R$ 100,00"
    amountType="positive"
  />
  <TransactionListReadOnly
    title="Negative"
    amount="R$ 100,00"
    amountType="negative"
  />
  <TransactionListReadOnly
    title="Strikethrough"
    amount="Grátis"
    strikethroughAmount="3,99%"
    amountType="strikethrough"
  />
  <TransactionListReadOnly
    title="Strikethrough Neutral"
    amount="R$ 2,00"
    strikethroughAmount="R$ 3,99"
    amountType="strikethrough-neutral"
  />
</List>
```

- **strikethrough**: o valor mudou a favor do cliente — original riscado (`Interface/Dark/Up`) e atual em verde (`Status/Positive/Deep`), na mesma linha.
- **strikethrough-neutral**: o valor só mudou — atual em `Interface/Dark/Deep`.

## Cor do ícone (iconColor)

A cor do ícone à esquerda vem de um conjunto fechado:

| Valor              | Token                 | Quando usar                                                                           |
| ------------------ | --------------------- | ------------------------------------------------------------------------------------- |
| `default` (padrão) | `Interface/Dark/Up`   | Linha sobre fundo branco                                                              |
| `on-color`         | `Interface/Dark/Down` | Linha sobre fundo colorido (ex.: heróis em `Status/Warning/Up`, `Status/Negative/Up`) |
| `highlight`        | `Brand/Primary/Down`  | Mais ênfase                                                                           |

Desabilitado **sempre** força `Interface/Light/Deep`, qualquer que seja a escolha — não é uma opção. O ícone herda a cor do componente: passe ícones **sem cor própria** (ex.: `<PlaceholderOutline size={24} />`, sem `color`).

## Estados

```tsx live
<List>
  <TransactionListReadOnly
    title="Desabilitado"
    description="Tipo inativo nos blocos"
    amount="R$ 0,00"
    amountTag={{ label: 'Label' }}
    icon={<PlaceholderOutline size={24} />}
    disabled
  />
  <TransactionListReadOnly
    title="Carregando"
    amount="R$ 0,00"
    icon={<PlaceholderOutline size={24} />}
    loading
  />
</List>
```

O desabilitado vem do tipo **Inactive** de conteúdo e valor (tag neutra), nunca de opacidade forçada.

## Divisor

O divisor (recuo de 16px, `mix-blend-mode: multiply`) aparece por padrão, como no Figma. Use `showDivider={false}` no último item quando o container já separa o grupo.

## Densidade (density)

`density="compact"` reduz o padding vertical da linha para 8 (Spacing/Xxs) — 16 no `default`. O padding horizontal, o espaço entre os elementos e o divisor não mudam; o esqueleto de carregamento acompanha. Figma: [node 26804-18127](https://www.figma.com/design/PgLv9k22CHHZZ867HwN65y/%F0%9F%8C%8A-Ocean-DS-Core?node-id=26804-18127).

## API

### Props

| Prop                       | Tipo                                                                                                       | Padrão      | Descrição                                                                                                                            |
| -------------------------- | ---------------------------------------------------------------------------------------------------------- | ----------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| `title`                    | `string`                                                                                                   | -           | Texto principal (obrigatório). Com `inverted` (padrão) é a linha menor acima da descrição                                            |
| `description`              | `string`                                                                                                   | -           | Texto secundário                                                                                                                     |
| `strikethroughDescription` | `string`                                                                                                   | -           | Texto riscado antes do texto em destaque, com `status="strikethrough"`                                                               |
| `caption`                  | `string`                                                                                                   | -           | Legenda (captionBold)                                                                                                                |
| `inverted`                 | `boolean`                                                                                                  | `true`      | Inverte título e descrição (Figma `Inverted=Yes`)                                                                                    |
| `status`                   | `'default' \| 'inactive' \| 'positive' \| 'warning' \| 'highlight' \| 'highlight-lead' \| 'strikethrough'` | `'default'` | Tipo do bloco de conteúdo                                                                                                            |
| `contentSize`              | `'md' \| 'sm'`                                                                                             | `'md'`      | Escala do texto, independente do valor                                                                                               |
| `amount`                   | `string`                                                                                                   | -           | Valor exibido à direita (obrigatório)                                                                                                |
| `amountType`               | `'default' \| 'positive' \| 'negative' \| 'inactive' \| 'strikethrough' \| 'strikethrough-neutral'`        | `'default'` | Tipo do valor                                                                                                                        |
| `amountSize`               | `'md' \| 'sm'`                                                                                             | `'md'`      | Tamanho do valor (md 16 / sm 14); a tag acompanha (Medium / Small)                                                                   |
| `strikethroughAmount`      | `string`                                                                                                   | -           | Valor original riscado antes de `amount` (tipos `strikethrough*`)                                                                    |
| `amountTag`                | `{ label: ReactNode; type?: TagType; setIconOff?: boolean }`                                               | -           | Tag abaixo do valor; tamanho vem de `amountSize`, fica `neutral` quando desabilitado                                                 |
| `amountIndicator`          | `ReactNode`                                                                                                | -           | Indicador livre abaixo do valor (quando `amountTag` não basta)                                                                       |
| `showAmountIndicator`      | `boolean`                                                                                                  | `true`      | Exibe a tag/indicador do valor                                                                                                       |
| `additionalData`           | `string`                                                                                                   | -           | Dado adicional abaixo do valor                                                                                                       |
| `disabled`                 | `boolean`                                                                                                  | `false`     | Conteúdo e valor usam o tipo inativo; a tag fica neutra                                                                              |
| `loading`                  | `boolean`                                                                                                  | `false`     | Exibe o esqueleto                                                                                                                    |
| `icon`                     | `ReactNode`                                                                                                | -           | Ícone à esquerda                                                                                                                     |
| `iconColor`                | `'default' \| 'on-color' \| 'highlight'`                                                                   | `'default'` | Cor do ícone (conjunto fechado); desabilitado sempre força `Interface/Light/Deep`                                                    |
| `density`                  | `'default' \| 'compact'`                                                                                   | `'default'` | Densidade vertical: `compact` usa padding de 8 (Spacing/Xxs) em cima e embaixo; o esqueleto acompanha. O padding horizontal não muda |
| `showDivider`              | `boolean`                                                                                                  | `true`      | Exibe o divisor abaixo do item                                                                                                       |
| `className`                | `string`                                                                                                   | -           | Classes CSS adicionais                                                                                                               |

## Acessibilidade

- Elemento `<div>` sem papel interativo; `aria-disabled` quando desabilitado e `aria-busy` durante o carregamento.

## Quando usar

- Valor monetário como peça principal, **sem** navegação, expansão ou seleção.
- Com navegação → [TransactionListAction](/components/transactionlistaction). Com seleção → [TransactionListSelectable](/components/transactionlistselectable). Com detalhes na própria lista → [TransactionListExpandable](/components/transactionlistexpandable).
