# Success Screen

Success Screen apresenta uma confirmação de conclusão com título claro, conteúdo relevante e uma saída adequada.

<StorybookEmbed
  storyId="components-feedback-success-screen-success-screen--positive"
  height={600}
/>

## Status

O status positivo comunica uma conclusão bem-sucedida. O status neutro apresenta um resultado sem indicar sucesso ou falha. O status negativo comunica uma conclusão malsucedida.

## Ações

As ações primária e secundária são exibidas no desktop. No mobile, elas são omitidas; o controle de fechar é opcional e usa `onClose`.

## Conteúdo

Inclua detalhes reais e úteis, como “Payment to supplier · Coral Distributors · R$ 6.819,33”. A altura da área de conteúdo é determinada pelos filhos.
