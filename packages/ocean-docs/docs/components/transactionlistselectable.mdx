# TransactionListSelectable

Linha de transação **selecionável pelo valor**, com caixa de marcar (padrão) ou opção única. Versão portal (`platform="web"`, controle à esquerda) e app (`platform="app"`, controle à direita). Faz parte da família Transaction List e fecha o gap de seleção em lista com valor no web.

Figma: [Transaction List Selectable](https://www.figma.com/design/PgLv9k22CHHZZ867HwN65y/%F0%9F%8C%8A-Ocean-DS-Core?node-id=24320-5708).

## Importação

```tsx
import { TransactionListSelectable } from '@useblu/ocean-react';
import type { TransactionListSelectableProps } from '@useblu/ocean-react';
```

## Caixa de marcar (web)

```tsx live
function Example() {
  const [checked, setChecked] = React.useState(false);

  return (
    <TransactionListSelectable
      title="Parcela 1 de 3"
      description="Vence em 10/11"
      amount="R$ 330,00"
      amountTag={{ label: 'Em aberto', type: 'warning' }}
      checkbox={{
        id: 'parcela-1',
        checked,
        onChange: () => setChecked(!checked),
      }}
    />
  );
}
```

## Opção única (app)

```tsx live
function Example() {
  const [selected, setSelected] = React.useState('a');

  return (
    <List>
      {['a', 'b'].map((id) => (
        <TransactionListSelectable
          key={id}
          platform="app"
          title={`Opção ${id.toUpperCase()}`}
          amount="R$ 100,00"
          radio={{
            id: `opcao-${id}`,
            name: 'opcoes',
            checked: selected === id,
            onChange: () => setSelected(id),
          }}
        />
      ))}
    </List>
  );
}
```

Não há ícone à esquerda: no Figma o controle ocupa esse lugar, então `iconColor` não se aplica.

## Estados

Todos os estados do Figma (`State` × Checkbox/Radio × App/Web) saem das props:

| Estado do Figma   | Props                                                     |
| ----------------- | --------------------------------------------------------- |
| Default           | controle sem `checked`                                    |
| Hover             | realce automático ao passar o mouse                       |
| Indeterminate     | `checkbox={{ indeterminate: true }}` (só caixa de marcar) |
| Selected          | `checked: true` no controle                               |
| Disabled          | `disabled`                                                |
| Disabled Selected | `disabled` + `checked: true`                              |
| Error             | `error: true` no controle                                 |
| Loading           | `loading`                                                 |

- `disabled` (ou `checkbox.disabled` / `radio.disabled`): desabilita o controle e usa o tipo inativo nos blocos.
- `checkbox.indeterminate` e `checkbox.error` / `radio.error`: estados do próprio controle.
- `loading`: esqueleto do controle e do conteúdo.

## API

### Props

| Prop                       | Tipo                                                                                                       | Padrão      | Descrição                                                                                 |
| -------------------------- | ---------------------------------------------------------------------------------------------------------- | ----------- | ----------------------------------------------------------------------------------------- |
| `title`                    | `string`                                                                                                   | -           | Texto principal (obrigatório). Com `inverted` (padrão) é a linha menor acima da descrição |
| `description`              | `string`                                                                                                   | -           | Texto secundário                                                                          |
| `strikethroughDescription` | `string`                                                                                                   | -           | Texto riscado antes do texto em destaque, com `status="strikethrough"`                    |
| `caption`                  | `string`                                                                                                   | -           | Legenda (captionBold)                                                                     |
| `inverted`                 | `boolean`                                                                                                  | `true`      | Inverte título e descrição (Figma `Inverted=Yes`)                                         |
| `status`                   | `'default' \| 'inactive' \| 'positive' \| 'warning' \| 'highlight' \| 'highlight-lead' \| 'strikethrough'` | `'default'` | Tipo do bloco de conteúdo                                                                 |
| `contentSize`              | `'md' \| 'sm'`                                                                                             | `'md'`      | Escala do texto, independente do valor                                                    |
| `amount`                   | `string`                                                                                                   | -           | Valor exibido à direita (obrigatório)                                                     |
| `amountType`               | `'default' \| 'positive' \| 'negative' \| 'inactive' \| 'strikethrough' \| 'strikethrough-neutral'`        | `'default'` | Tipo do valor                                                                             |
| `amountSize`               | `'md' \| 'sm'`                                                                                             | `'md'`      | Tamanho do valor (md 16 / sm 14); a tag acompanha (Medium / Small)                        |
| `strikethroughAmount`      | `string`                                                                                                   | -           | Valor original riscado antes de `amount` (tipos `strikethrough*`)                         |
| `amountTag`                | `{ label: ReactNode; type?: TagType; setIconOff?: boolean }`                                               | -           | Tag abaixo do valor; tamanho vem de `amountSize`, fica `neutral` quando desabilitado      |
| `amountIndicator`          | `ReactNode`                                                                                                | -           | Indicador livre abaixo do valor (quando `amountTag` não basta)                            |
| `showAmountIndicator`      | `boolean`                                                                                                  | `true`      | Exibe a tag/indicador do valor                                                            |
| `additionalData`           | `string`                                                                                                   | -           | Dado adicional abaixo do valor                                                            |
| `disabled`                 | `boolean`                                                                                                  | `false`     | Conteúdo e valor usam o tipo inativo; a tag fica neutra                                   |
| `loading`                  | `boolean`                                                                                                  | `false`     | Exibe o esqueleto                                                                         |
| `checkbox`                 | `CheckboxProps`                                                                                            | -           | Props da caixa de marcar (controle padrão)                                                |
| `radio`                    | `RadioProps`                                                                                               | -           | Props da opção única; quando informado, substitui a caixa de marcar                       |
| `platform`                 | `'web' \| 'app'`                                                                                           | `'web'`     | `web`: controle à esquerda; `app`: controle à direita                                     |
| `showDivider`              | `boolean`                                                                                                  | `true`      | Exibe o divisor abaixo do item                                                            |
| `className`                | `string`                                                                                                   | -           | Classes CSS adicionais                                                                    |

## Acessibilidade

- O item inteiro é o `<label>` do controle: clicar em qualquer ponto marca/desmarca. Use `id` no controle e `name` nos radios do mesmo grupo.
