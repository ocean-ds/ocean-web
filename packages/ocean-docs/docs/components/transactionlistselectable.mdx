# TransactionListSelectable

Linha de transação **selecionável pelo valor**, com caixa de marcar (padrão) ou opção única. Versão portal (`platform="web"`, controle à esquerda) e app (`platform="app"`, controle à direita). Faz parte da família Transaction List.

## Importação

```tsx
import { TransactionListSelectable } from '@useblu/ocean-react';
import type {
  TransactionListSelectableProps,
  ContentListDefaultProps,
  ContentListAmountProps,
} from '@useblu/ocean-react';
```

## Caixa de marcar (web)

```tsx live
function Example() {
  const [checked, setChecked] = React.useState(false);

  return (
    <TransactionListSelectable
      content={{ title: 'Parcela 1 de 3', description: 'Vence em 10/11' }}
      amount={{
        value: 'R$ 330,00',
        tag: { label: 'Em aberto', type: 'warning' },
      }}
      checkbox={{
        id: 'parcela-1',
        checked,
        onChange: () => setChecked(!checked),
      }}
    />
  );
}
```

## Opção única (app)

```tsx live
function Example() {
  const [selected, setSelected] = React.useState('a');

  return (
    <List>
      {['a', 'b'].map((id) => (
        <TransactionListSelectable
          key={id}
          platform="app"
          content={{ title: `Opção ${id.toUpperCase()}` }}
          amount={{ value: 'R$ 100,00' }}
          radio={{
            id: `opcao-${id}`,
            name: 'opcoes',
            checked: selected === id,
            onChange: () => setSelected(id),
          }}
        />
      ))}
    </List>
  );
}
```

Não há ícone à esquerda: o controle ocupa esse lugar, então `iconColor` não se aplica.

## Estados

Todos os estados (Checkbox/Radio × App/Web) saem das props:

| Estado            | Props                                                     |
| ----------------- | --------------------------------------------------------- |
| Default           | controle sem `checked`                                    |
| Hover             | realce automático ao passar o mouse                       |
| Indeterminate     | `checkbox={{ indeterminate: true }}` (só caixa de marcar) |
| Selected          | `checked: true` no controle                               |
| Disabled          | `disabled`                                                |
| Disabled Selected | `disabled` + `checked: true`                              |
| Error             | `error: true` no controle                                 |
| Loading           | `loading`                                                 |

- `disabled` (ou `checkbox.disabled` / `radio.disabled`): desabilita o controle e usa o tipo inativo nos blocos.
- `checkbox.indeterminate` e `checkbox.error` / `radio.error`: estados do próprio controle.
- `loading`: esqueleto do controle e do conteúdo.

## Textos longos

Os textos do conteúdo e a informação do valor (`amount.info`) quebram em até **duas linhas** e depois são cortados com reticências; o corte é só visual, então leitores de tela leem o texto completo. A tag fica em uma linha; rótulos longos são truncados com reticências, e o rótulo completo fica disponível como dica (`title`).

## Densidade (density)

`density="compact"` reduz o padding vertical da linha para 8 (Spacing/Xxs) — 16 no `default`. O padding horizontal, o espaço entre os elementos e o divisor não mudam; o esqueleto de carregamento acompanha.

## API

### Props

| Prop          | Tipo                      | Padrão      | Descrição                                                                                                                                                                                                                 |
| ------------- | ------------------------- | ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `content`     | `ContentListDefaultProps` | -           | Bloco de conteúdo à esquerda (obrigatório): `title`, `description`, `strikethroughDescription`, `caption`, `inverted`, `status`, `size`. Campos em [TransactionListReadOnly](/components/transactionlistreadonly#content) |
| `amount`      | `ContentListAmountProps`  | -           | Bloco de valor à direita (obrigatório): `value`, `type`, `strikethroughValue`, `tag`, `info`, `size`. Campos em [TransactionListReadOnly](/components/transactionlistreadonly#amount)                                     |
| `disabled`    | `boolean`                 | `false`     | Conteúdo e valor usam o tipo inativo; a tag fica neutra                                                                                                                                                                   |
| `loading`     | `boolean`                 | `false`     | Exibe o esqueleto                                                                                                                                                                                                         |
| `density`     | `'default' \| 'compact'`  | `'default'` | Densidade vertical: `compact` usa padding de 8 (Spacing/Xxs) em cima e embaixo; o esqueleto acompanha. O padding horizontal não muda                                                                                      |
| `checkbox`    | `CheckboxProps`           | -           | Props da caixa de marcar (controle padrão)                                                                                                                                                                                |
| `radio`       | `RadioProps`              | -           | Props da opção única; quando informado, substitui a caixa de marcar                                                                                                                                                       |
| `platform`    | `'web' \| 'app'`          | `'web'`     | `web`: controle à esquerda; `app`: controle à direita                                                                                                                                                                     |
| `showDivider` | `boolean`                 | `true`      | Exibe o divisor abaixo do item                                                                                                                                                                                            |
| `className`   | `string`                  | -           | Classes CSS adicionais                                                                                                                                                                                                    |

## Acessibilidade

- O item inteiro é o `<label>` do controle: clicar em qualquer ponto marca/desmarca, e o nome do controle inclui título, descrição e valor. Use `id` no controle e `name` nos radios do mesmo grupo.
