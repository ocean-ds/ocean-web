# TransactionListExpandable

O componente TransactionListExpandable é uma variação do ListExpandable otimizada para exibir transações financeiras com suporte a valores, indicadores e dados adicionais, permitindo expandir para mostrar detalhes ou ações relacionadas.

## Importação

```tsx
import { TransactionListExpandable } from '@useblu/ocean-react';
```

### Importação específica (recomendado para tree-shaking)

```tsx
import { TransactionListExpandable } from '@useblu/ocean-react/TransactionListExpandable';
```

### Importação de tipos TypeScript

```tsx
import type {
  TransactionListExpandableProps,
  ContentListDefaultProps,
  ContentListAmountProps,
} from '@useblu/ocean-react';

// Uso em componente customizado
const MyComponent: React.FC<TransactionListExpandableProps> = (props) => {
  return <TransactionListExpandable {...props} />;
};
```

## Uso básico

```tsx live
<TransactionListExpandable
  content={{ title: 'Transferência PIX', description: 'João Silva' }}
  amount={{ value: 'R$ 150,00' }}
  icon={<PlaceholderOutline size={24} />}
>
  <div style={{ padding: '16px' }}>
    <p>Detalhes da transação...</p>
  </div>
</TransactionListExpandable>
```

A linha principal recebe os mesmos blocos `content` e `amount` do resto da família Transaction List. As props planas antigas (`title`, `description`, `amountType`, `amountTag`, `additionalData`…) continuam funcionando, mas estão **deprecated**: veja [Migração da API plana](#migração-da-api-plana).

## Estados de Expansão

O TransactionListExpandable pode ser usado em modo controlado:

### Controlled

```tsx
const [expanded, setExpanded] = useState(false);

<TransactionListExpandable
  content={{ title: 'Transferência PIX', description: 'João Silva' }}
  amount={{ value: 'R$ 150,00' }}
  expanded={expanded}
  onToggle={(newExpanded) => setExpanded(newExpanded)}
>
  <div>Detalhes da transferência</div>
</TransactionListExpandable>;
```

## Com os itens filhos da família

Use [TransactionListChildAction / TransactionListChildReadOnly](/components/transactionlistchild) como filhos, com `position` formando a linha do tempo. `content.size`, `amount.size` e `amount.tag` são opcionais: sem eles a renderização atual da linha principal não muda.

```tsx live
function Example() {
  const [expanded, setExpanded] = React.useState(true);

  return (
    <div style={{ maxWidth: 360 }}>
      <TransactionListExpandable
        content={{ title: 'Vendas do dia', description: '3 transações' }}
        amount={{ value: 'R$ 300,00', size: 'md', tag: { label: 'Recebido' } }}
        icon={<PlaceholderOutline size={24} />}
        expanded={expanded}
        onToggle={setExpanded}
        supportingText="Valores líquidos"
        showDivider
      >
        {['first', 'middle', 'last'].map((position) => (
          <TransactionListChildAction
            key={position}
            content={{ title: 'Cartão de crédito', description: 'Venda' }}
            amount={{ value: 'R$ 100,00' }}
            icon={<Placeholder size={16} />}
            position={position}
          />
        ))}
      </TransactionListExpandable>
    </div>
  );
}
```

## Textos longos

Os textos do conteúdo e a informação do valor (`amount.info`) quebram em até **duas linhas** e depois são cortados com reticências; o corte é só visual, então leitores de tela leem o texto completo. A tag fica em uma linha; rótulos longos são truncados com reticências, e o rótulo completo fica disponível como dica (`title`).

## Densidade (density)

`density="compact"` reduz o padding vertical da linha para 8 (Spacing/Xxs) — 16 no `default`. Na Expandable é opt-in e vale para a linha principal; os filhos recebem o próprio `density`. O padding horizontal, o espaço entre os elementos e o divisor não mudam; o esqueleto de carregamento acompanha.

## Migração da API plana

Cada prop plana tem um campo equivalente em `content` ou `amount`. Quando `content` é informado, ele tem prioridade sobre as props planas de conteúdo; quando `amount` é um objeto, as props planas de valor são ignoradas.

| Prop plana (deprecated)    | Use                                                     |
| -------------------------- | ------------------------------------------------------- |
| `title`                    | `content.title`                                         |
| `description`              | `content.description`                                   |
| `strikethroughDescription` | `content.strikethroughDescription`                      |
| `caption`                  | `content.caption`                                       |
| `inverted`                 | `content.inverted`                                      |
| `status`                   | `content.status`                                        |
| `contentSize`              | `content.size`                                          |
| `amount` (string)          | `amount.value`                                          |
| `amountType`               | `amount.type`                                           |
| `strikethroughAmount`      | `amount.strikethroughValue`                             |
| `amountSize`               | `amount.size`                                           |
| `amountTag`                | `amount.tag`                                            |
| `additionalData`           | `amount.info`                                           |
| `amountIndicator`          | `amount.tag` (só funciona com `amount` em string)       |
| `showAmountIndicator`      | omita `amount.tag` (só funciona com `amount` em string) |

```tsx
// Antes (deprecated)
<TransactionListExpandable
  title="Pagamento"
  amount="R$ 150,00"
  amountType="negative"
  amountTag={{ label: 'Débito', type: 'negative' }}
  additionalData="Conta digital"
/>

// Depois
<TransactionListExpandable
  content={{ title: 'Pagamento' }}
  amount={{
    value: 'R$ 150,00',
    type: 'negative',
    tag: { label: 'Débito', type: 'negative' },
    info: 'Conta digital',
  }}
/>
```

### Props deprecated

Continuam funcionando para não quebrar quem já usa a API plana. Prefira `content` e `amount` (ver [Migração da API plana](#migração-da-api-plana)).

| Prop                       | Tipo                                                                                                       | Padrão      | Use no lugar                       |
| -------------------------- | ---------------------------------------------------------------------------------------------------------- | ----------- | ---------------------------------- |
| `title`                    | `string`                                                                                                   | -           | `content.title`                    |
| `description`              | `string`                                                                                                   | -           | `content.description`              |
| `strikethroughDescription` | `string`                                                                                                   | -           | `content.strikethroughDescription` |
| `caption`                  | `string`                                                                                                   | -           | `content.caption`                  |
| `inverted`                 | `boolean`                                                                                                  | `true`      | `content.inverted`                 |
| `status`                   | `'default' \| 'inactive' \| 'positive' \| 'warning' \| 'highlight' \| 'highlight-lead' \| 'strikethrough'` | `'default'` | `content.status`                   |
| `contentSize`              | `'md' \| 'sm'`                                                                                             | -           | `content.size`                     |
| `amountType`               | `'default' \| 'positive' \| 'negative' \| 'strikethrough' \| 'strikethrough-neutral'`                      | `'default'` | `amount.type`                      |
| `strikethroughAmount`      | `string`                                                                                                   | -           | `amount.strikethroughValue`        |
| `amountSize`               | `'md' \| 'sm'`                                                                                             | -           | `amount.size`                      |
| `amountTag`                | `{ label: ReactNode; type?: TagType; setIconOff?: boolean }`                                               | -           | `amount.tag`                       |
| `additionalData`           | `string`                                                                                                   | -           | `amount.info`                      |

`amountIndicator` (`ReactNode`) e `showAmountIndicator` (`boolean`, padrão `true`) só têm efeito com `amount` em string; com o bloco `amount`, use `amount.tag`.

### Eventos

- **onToggle**: Disparado quando o item é expandido ou recolhido, recebe o novo estado como parâmetro

## Acessibilidade

- ✅ Elemento `<button>` semântico para ação de expansão
- ✅ Atributo `aria-expanded` para comunicar o estado aos leitores de tela
- ✅ Rótulos `aria-label` automatizados para clarificar a ação ("Expandir/Recolher [Título]")
- ✅ Textos longos cortados só visualmente: leitores de tela leem o conteúdo e o rótulo da tag completos
- ✅ Suporte completo à navegação por teclado
- ✅ Estados de foco visíveis via `focus-visible`
- ✅ Estado `disabled` corretamente aplicado ao botão
- ✅ Indicadores visuais claros (ícones de chevron)
- ✅ Skeleton acessível durante loading

### Navegação por teclado

| Tecla             | Função                           |
| ----------------- | -------------------------------- |
| `Tab`             | Move foco para o item            |
| `Space` / `Enter` | Expande ou recolhe o conteúdo    |
| `Shift + Tab`     | Move foco para elemento anterior |

## Melhores práticas

### ✅ Faça

- Use `amount.type` para diferenciar entradas (positive) de saídas (negative)
- Forneça um `icon` que ajude a identificar rapidamente a categoria da transação
- Use `supportingText` para informações complementares importantes que não cabem no header
- Utilize o estado `loading` enquanto busca detalhes pesados da transação
- Use `amount.tag` para mostrar o status da transação (Crédito, Débito)
- Combine com `List` para agrupar múltiplas transações
- Implemente `onToggle` para tracking de interações do usuário
- Use `amount.info` para exibir informações auxiliares como data ou parcela
- Use os blocos `content` e `amount` em vez das props planas (deprecated)
- Use `showDivider` quando precisar separar visualmente header do conteúdo expandido

### ❌ Não faça

- Não coloque informações cruciais apenas no conteúdo expandido se o usuário precisar vê-las de relance
- Evite aninhamentos excessivos de componentes expansíveis
- Não use `disabled` e `loading` simultaneamente
- Não omita o `amount` (é obrigatório)
- Não misture `content`/`amount` com as props planas na mesma linha: as props planas são ignoradas
- Não abuse de itens expandidos na mesma tela (pode confundir)
- Evite textos excessivamente longos no `supportingText`

### Uso de Valores

- **Positivos**: Use `amount.type: 'positive'` para receitas, créditos, entradas
- **Negativos**: Use `amount.type: 'negative'` para despesas, débitos, saídas
- **Padrão**: Use `amount.type: 'default'` para valores informativos sem conotação
- **Formatação**: Inclua símbolo da moeda e formatação adequada, sem sinal (ex: "R$ 1.234,56"); o sinal vem de `amount.type`

## Casos de uso comuns

### 1. Extrato de Transações

```tsx
<List>
  <TransactionListExpandable
    content={{ title: 'Transferência PIX', description: 'João Silva' }}
    amount={{
      value: 'R$ 250,00',
      type: 'negative',
      tag: { label: 'Débito', type: 'negative' },
    }}
    icon={<PixIcon size={24} />}
  >
    <TransactionDetails id="pix-123" />
  </TransactionListExpandable>
  <TransactionListExpandable
    content={{ title: 'Depósito', description: 'Salário - Empresa LTDA' }}
    amount={{
      value: 'R$ 5.000,00',
      type: 'positive',
      tag: { label: 'Crédito', type: 'positive' },
    }}
    icon={<DepositIcon size={24} />}
  >
    <TransactionDetails id="dep-456" />
  </TransactionListExpandable>
</List>
```

### 2. Detalhes de Cobrança com Ações

```tsx
<TransactionListExpandable
  content={{ title: 'Cobrança PIX', description: 'Cliente ABC' }}
  amount={{
    value: 'R$ 1.500,00',
    type: 'positive',
    info: 'Vencimento: 20/01/2026',
  }}
  icon={<BarcodeIcon size={24} />}
  supportingText="Cobrança enviada em 10/01/2026"
>
  <ListAction icon={<CopyIcon />} title="Copiar código" />
  <ListAction icon={<ShareIcon />} title="Compartilhar cobrança" />
</TransactionListExpandable>
```

### 3. Lista de Pagamentos com Loading

```tsx
<List>
  {isLoading ? (
    <>
      <TransactionListExpandable
        content={{ title: '' }}
        amount={{ value: '' }}
        loading
      />
      <TransactionListExpandable
        content={{ title: '' }}
        amount={{ value: '' }}
        loading
      />
    </>
  ) : (
    payments.map((payment) => (
      <TransactionListExpandable
        key={payment.id}
        content={{
          title: payment.description,
          description: payment.recipient,
        }}
        amount={{ value: payment.formattedAmount, type: payment.type }}
        icon={<PaymentIcon size={24} />}
      >
        <PaymentDetails payment={payment} />
      </TransactionListExpandable>
    ))
  )}
</List>
```
