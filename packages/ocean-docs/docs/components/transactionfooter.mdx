# Transaction Footer

`TransactionFooter` organiza as linhas de uma transação, o total e a ação principal na parte inferior da tela. Cada linha usa `TransactionListReadOnly`: a primeira mantém a densidade padrão e as demais usam a densidade compacta. O componente exibe no máximo cinco linhas, sem contar o total.

## Importação

```tsx
import { TransactionFooter } from '@useblu/ocean-react';
```

## Exemplo

```tsx live
<TransactionFooter
  type="highlight"
  items={[
    {
      content: { title: 'Compra', description: 'Loja' },
      amount: { value: 'R$ 100,00' },
    },
    {
      content: { title: 'Desconto' },
      amount: { value: 'R$ 10,00', type: 'positive' },
    },
  ]}
  total={{ label: 'Total', value: 'R$ 90,00' }}
  action={
    <Button variant="primary" blocked>
      Continuar
    </Button>
  }
/>
```

## Propriedades

| Propriedade | Tipo                                     | Obrigatória | Descrição                                                                                                                          |
| ----------- | ---------------------------------------- | ----------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| `type`      | `'default' \| 'highlight'`               | Não         | Aparência. `default` usa fundo branco e borda superior; `highlight` usa fundo `colorInterfaceLightUp` e cantos superiores de 12px. |
| `items`     | `TransactionListReadOnlyProps[]`         | Sim         | Linhas de transação. A primeira é exibida em densidade padrão e as seguintes em densidade compacta.                                |
| `total`     | `{ label: ReactNode; value: ReactNode }` | Sim         | Rótulo e valor do total, exibidos depois das linhas.                                                                               |
| `notice`    | `ReactNode`                              | Não         | Aviso exibido antes das linhas e do total.                                                                                         |
| `action`    | `ReactNode`                              | Sim         | Ação fornecida pelo consumidor; há 32px entre o total e a ação.                                                                    |

O componente também aceita `className` e atributos válidos de uma `<div>`.

## Estilo

O footer usa tokens Ocean para cores, espaçamentos e bordas. O aviso usa fundo `#f2fcf5` com `#2da94f` aplicado a 12%, conforme definido para este componente.

## Boas práticas

- Passe os dados de cada linha nas propriedades existentes de `TransactionListReadOnly`, incluindo descrição, informação extra, tag ou valores riscados.
- Passe o botão Ocean no campo `action`; o componente não define a ação de negócio.
- Limite os itens ao que é mais importante: linhas além das cinco primeiras não são exibidas.
