# Transaction Footer

`TransactionFooter` organiza as linhas de uma transação, o total, um aviso opcional e a ação principal na parte inferior de uma tela móvel de pagamento. Cada linha usa `TransactionListReadOnly`: a primeira mantém a densidade padrão e as demais usam a densidade compacta. O componente exibe no máximo cinco linhas, sem contar o total. Posicionamento fixo e área segura continuam sob responsabilidade da tela.

## Importação

```tsx
import { TransactionFooter } from '@useblu/ocean-react';
```

## Exemplo

```tsx live
<TransactionFooter
  type="highlight"
  items={[
    {
      content: { title: 'Pedido' },
      amount: { value: 'R$ 623,80' },
    },
    {
      content: { title: 'Pague em' },
      amount: { value: '3x de R$ 207,93', info: 'sem acréscimo' },
    },
  ]}
  total={{ label: 'Total', value: 'R$ 623,80' }}
  notice={{
    title: 'Economia de R$ 96,39',
    description: 'Economia aplicada ao seu pagamento.',
  }}
  action={
    <Button variant="primary" blocked>
      Revisar pagamento
    </Button>
  }
/>
```

## Propriedades

| Propriedade | Tipo                                     | Obrigatória | Descrição                                                                                                                               |
| ----------- | ---------------------------------------- | ----------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| `type`      | `'default' \| 'highlight'`               | Não         | Aparência. `default` usa fundo branco e borda superior; `highlight` usa fundo `colorInterfaceLightUp` e cantos superiores de 12px.      |
| `items`     | `TransactionListReadOnlyProps[]`         | Sim         | Linhas de transação. A primeira é exibida em densidade padrão e as seguintes em densidade compacta.                                     |
| `total`     | `{ label: ReactNode; value: ReactNode }` | Sim         | Rótulo e valor do total, exibidos depois das linhas e do divisor.                                                                       |
| `notice`    | `TransactionNoticeProps`                 | Não         | `{ title: ReactNode; description?: ReactNode; icon?: ReactNode }`. O título é obrigatório; sem ícone, usa-se o check positivo do Ocean. |
| `action`    | `ReactNode`                              | Sim         | Ação fornecida pelo consumidor, em largura total dentro do rodapé.                                                                      |

O componente também aceita `className` e atributos válidos de uma `<div>`.

## Estilo

O Footer usa tokens Ocean para cores, espaçamentos, tipografia e bordas. O aviso combina `colorStatusPositiveUp` com uma sobreposição de 12% de `colorStatusPositiveDeep`.

## Boas práticas

- Passe os dados de cada linha nas propriedades existentes de `TransactionListReadOnly`, incluindo descrição, informação extra, tag ou valores riscados.
- Passe o botão Ocean no campo `action`; o componente não define a ação de negócio.
- Limite os itens ao que é mais importante: linhas além das cinco primeiras não são exibidas.
- Use o Footer na parte inferior de uma tela de pagamento móvel; sticky e área segura são responsabilidade da tela.
