# Transaction Footer

`TransactionFooter` reúne o item principal opcional, detalhes opcionais, o total obrigatório, um aviso opcional e a ação principal de uma tela móvel de pagamento. Cada linha contém `label`, `value` e `info` opcional abaixo do valor; `mainItem` e `details` são independentes. O componente renderiza todos os detalhes recebidos. Use no máximo quatro detalhes como regra de uso da tela, sem contar o total.

O aviso é uma peça separada acima do corpo; o corpo se sobrepõe a ele. O ícone recomendado é um check-circle sólido, centralizado verticalmente.

## Importação

```tsx
import { TransactionFooter } from '@useblu/ocean-react';
import type {
  TransactionFooterProps,
  TransactionNoticeProps,
  TransactionRow,
} from '@useblu/ocean-react';
```

## Exemplo

```tsx live
<TransactionFooter
  type="default"
  mainItem={{ label: 'Subtotal', value: 'R$ 1.250,00' }}
  details={[
    { label: 'Parcelamento', value: '5x de R$ 250,00', info: 'sem acréscimo' },
  ]}
  total={{ label: 'Total', value: 'R$ 1.250,00' }}
  notice={{
    title: 'Desconto aplicado',
    description: 'Texto de apoio do aviso.',
  }}
  action={
    <Button variant="primary" blocked>
      Continuar
    </Button>
  }
/>
```

## Propriedades

| Propriedade | Tipo                       | Obrigatória | Descrição                                                                                                                                                                                          |
| ----------- | -------------------------- | ----------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `type`      | `'default' \| 'highlight'` | Não         | Aparência do corpo. `default` usa fundo branco e borda superior; `highlight` usa fundo `colorInterfaceLightUp`.                                                                                    |
| `mainItem`  | `TransactionRow`           | Não         | Linha opcional com `{ label, value, info? }`, em densidade padrão. A informação fica abaixo do valor; não é inferida do primeiro detalhe.                                                          |
| `details`   | `TransactionRow[]`         | Não         | Linhas opcionais com `{ label, value, info? }`, em densidade compacta. Use no máximo quatro como regra da tela; o componente não corta a lista.                                                    |
| `total`     | `TransactionRow`           | Sim         | Linha `{ label, value }` obrigatória, em negrito.                                                                                                                                                  |
| `notice`    | `TransactionNoticeProps`   | Não         | Aviso opcional: `{ title?: ReactNode; description: ReactNode; icon?: ReactNode }`. Título opcional; descrição obrigatória. Sem `icon`, usa o check-circle sólido do Ocean; `icon={null}` o oculta. |
| `action`    | `ReactNode`                | Sim         | Ação fornecida pelo consumidor, em largura total dentro do corpo.                                                                                                                                  |
| `className` | `string`                   | Não         | Classe CSS adicional para a raiz.                                                                                                                                                                  |

O componente também aceita atributos válidos de uma `<div>`.

## Densidade e divisores

- A linha principal e o total usam densidade padrão; os detalhes usam densidade compacta.
- Há um divisor depois do item principal quando detalhes vêm em seguida e um divisor antes do total sempre que existe uma linha acima.
- Sem item principal e sem detalhes, o total aparece sem divisor.
- A ordem permanece `mainItem`, `details`, `total`; o componente renderiza todos os detalhes recebidos.

## Boas práticas

- Cada linha contém rótulo, valor e informação opcional abaixo do valor. Não passe ícone, descrição, legenda, tag ou valor riscado.
- Use no máximo quatro detalhes como regra de uso da tela; esse número não é um limite de renderização do componente.
- Passe o botão Ocean por `action`; o componente não define a ação de negócio.
