# Itens filhos da Transaction List

`TransactionListChildAction` (com seta) e `TransactionListChildReadOnly` (sem seta) são os itens que aparecem **dentro** da [TransactionListExpandable](/components/transactionlistexpandable), ligados por uma linha do tempo. Recebem os mesmos blocos `content` e `amount` da família e, por padrão, usam a escala compacta (`content.size` e `amount.size` em `sm`).

## Importação

```tsx
import {
  TransactionListChildAction,
  TransactionListChildReadOnly,
} from '@useblu/ocean-react';
```

## Posição na linha do tempo (position)

| Valor                 | Linha                 |
| --------------------- | --------------------- |
| `standalone` (padrão) | sem linha             |
| `first`               | linha abaixo do ícone |
| `middle`              | linha acima e abaixo  |
| `last`                | linha acima do ícone  |

```tsx live
<div style={{ maxWidth: 360 }}>
  <TransactionListChildAction
    content={{ title: 'Parcela 1', description: 'Paga' }}
    amount={{ value: 'R$ 100,00' }}
    icon={<Placeholder size={16} />}
    position="first"
  />
  <TransactionListChildAction
    content={{ title: 'Parcela 2', description: 'Paga' }}
    amount={{ value: 'R$ 100,00' }}
    icon={<Placeholder size={16} />}

  />
  <TransactionListChildReadOnly
    content={{ title: 'Parcela 3', description: 'A vencer' }}

    position="last"
    disabled
  />
</div>
```

## Cor do ícone (iconColor)

A cor do ícone à esquerda vem de um conjunto fechado:

| Valor              | Token                 | Quando usar                                                                           |
| ------------------ | --------------------- | ------------------------------------------------------------------------------------- |
| `default` (padrão) | `Interface/Dark/Up`   | Linha sobre fundo branco                                                              |
| `on-color`         | `Interface/Dark/Down` | Linha sobre fundo colorido (ex.: heróis em `Status/Warning/Up`, `Status/Negative/Up`) |
| `highlight`        | `Brand/Primary/Down`  | Mais ênfase                                                                           |

Nos itens filhos (também quando usados na `TransactionListExpandable`), **sem `iconColor`** o ícone usa `Interface/Light/Down`; um `default`, `on-color` ou `highlight` explícito substitui essa cor.

Desabilitado **sempre** força `Interface/Light/Deep`, qualquer que seja a escolha — não é uma opção. O ícone herda a cor do componente: passe ícones **sem cor própria** (ex.: `<PlaceholderOutline size={24} />`, sem `color`).

## Textos longos

Os textos do conteúdo e a informação do valor (`amount.info`) quebram em até **duas linhas** e depois são cortados com reticências; o corte é só visual, então leitores de tela leem o texto completo. A tag fica em uma linha; rótulos longos são truncados com reticências, e o rótulo completo fica disponível como dica (`title`).

## Densidade (density)

`density="compact"` reduz o padding vertical da linha para 8 (Spacing/Xxs) — 12 no `default` dos filhos. O padding horizontal, o espaço entre os elementos e o divisor não mudam; o esqueleto de carregamento acompanha.

## API

As duas compartilham as props da família:

| Prop        | Tipo                                            | Padrão         | Descrição                                                                                                                                                                                                                      |
| ----------- | ----------------------------------------------- | -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `content`   | `ContentListDefaultProps`                       | -              | Bloco de conteúdo (obrigatório): `title`, `description`, `strikethroughDescription`, `caption`, `inverted`, `status`, `size` (padrão `'sm'`). Campos em [TransactionListReadOnly](/components/transactionlistreadonly#content) |
| `amount`    | `ContentListAmountProps`                        | -              | Bloco de valor (obrigatório): `value`, `type`, `strikethroughValue`, `tag`, `info`, `size` (padrão `'sm'`). Campos em [TransactionListReadOnly](/components/transactionlistreadonly#amount)                                    |
| `icon`      | `ReactNode`                                     | -              | Ícone de 16px no centro da linha do tempo                                                                                                                                                                                      |
| `iconColor` | `'default' \| 'on-color' \| 'highlight'`        | -              | Sem a prop: `Interface/Light/Down` (padrão do filho). Explícito substitui; desabilitado sempre força `Interface/Light/Deep`                                                                                                    |
| `disabled`  | `boolean`                                       | `false`        | Conteúdo e valor usam o tipo inativo; a tag fica neutra                                                                                                                                                                        |
| `loading`   | `boolean`                                       | `false`        | Exibe o esqueleto                                                                                                                                                                                                              |
| `density`   | `'default' \| 'compact'`                        | `'default'`    | Densidade vertical: `compact` usa padding de 8 (Spacing/Xxs) em cima e embaixo; o esqueleto acompanha. O padding horizontal não muda                                                                                           |
| `position`  | `'standalone' \| 'first' \| 'middle' \| 'last'` | `'standalone'` | Posição na linha do tempo                                                                                                                                                                                                      |
| `className` | `string`                                        | -              | Classes CSS no elemento raiz                                                                                                                                                                                                   |

`TransactionListChildAction` também recebe `onClick` (um disparo por toque; nada com `disabled`/`loading`) e encaminha `ref` e as demais props para o `<button>`.
