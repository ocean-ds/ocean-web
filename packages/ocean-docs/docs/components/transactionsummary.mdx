# Transaction Summary

`TransactionSummary` reúne linhas somente de leitura em um card para a coluna lateral de uma tela desktop, com título, aviso e ação opcionais. A primeira linha usa densidade padrão; as demais usam densidade compacta. São exibidas no máximo cinco linhas, sem contar o total. Posicionamento fixo e área segura continuam sob responsabilidade da tela.

## Importação

```tsx
import { TransactionSummary } from '@useblu/ocean-react';
```

## Exemplo

```tsx live
<TransactionSummary
  title="Resumo"
  items={[
    {
      content: { title: 'Pedido' },
      amount: { value: 'R$ 623,80' },
    },
    {
      content: { title: 'Pague em' },
      amount: { value: '3x de R$ 207,93', info: 'sem acréscimo' },
    },
  ]}
  total={{ label: 'Total', value: 'R$ 623,80' }}
  notice={{
    title: 'Economia de R$ 96,39',
    description: 'Economia aplicada ao seu pagamento.',
  }}
  action={
    <Button variant="primary" blocked>
      Revisar pagamento
    </Button>
  }
/>
```

## Propriedades

| Propriedade | Tipo                                     | Obrigatória | Descrição                                                                                                                               |
| ----------- | ---------------------------------------- | ----------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| `title`     | `ReactNode`                              | Não         | Título acima do card, exibido em `colorInterfaceDarkUp`.                                                                                |
| `items`     | `TransactionListReadOnlyProps[]`         | Sim         | Linhas da transação. A primeira é exibida em densidade padrão e as seguintes em densidade compacta.                                     |
| `total`     | `{ label: ReactNode; value: ReactNode }` | Sim         | Rótulo e valor do total, separados das linhas por um divisor.                                                                           |
| `notice`    | `TransactionNoticeProps`                 | Não         | `{ title: ReactNode; description?: ReactNode; icon?: ReactNode }`. O título é obrigatório; sem ícone, usa-se o check positivo do Ocean. |
| `action`    | `ReactNode`                              | Não         | Ação exibida em largura total fora do card, abaixo do aviso opcional.                                                                   |

O componente também aceita `className` e atributos válidos de uma `<div>`.

## Estilo

O card usa `colorInterfaceLightUp` e cantos de 12px (`borderRadiusMd`). O aviso combina `colorStatusPositiveUp` com uma sobreposição de 12% de `colorStatusPositiveDeep`. As demais cores, tipografia e espaçamentos usam tokens Ocean.

## Boas práticas

- Use Summary na coluna lateral de uma tela desktop; o componente está disponível somente na Web.
- Passe no máximo cinco linhas, sem contar o total.
- Mantenha a ação fora do card; ela aparece depois do card e do aviso opcional.
- Sticky, posicionamento e área segura são responsabilidade da tela.
