TransactionListReadOnly

Linha de transação só de leitura: conteúdo à esquerda e valor à direita, sem interação. Faz parte da família Transaction List (Read Only, Action, Selectable, Expandable e os itens filhos), que substitui o TransactionListItem.

Toda linha da família recebe dois blocos: content (o que aconteceu e com quem) e amount (o valor, com tag e informação opcionais).

Importação​

import { TransactionListReadOnly } from '@useblu/ocean-react';

Importação de tipos TypeScript​

import type {
  TransactionListReadOnlyProps,
  ContentListDefaultProps,
  ContentListAmountProps,
} from '@useblu/ocean-react';

Playground Interativo​

🚀 Abrir no Storybook

Uso básico​

<TransactionListReadOnly
  content={{
    title: 'Pix recebido',
    description: 'Loja Exemplo',
    caption: 'Hoje às 14:32',
  }}
  amount={{
    value: 'R$ 150,00',
    tag: { label: 'Aprovado' },
    info: 'Saldo disponível',
  }}
  icon={<PlaceholderOutline size={24} />}
/>

Tamanhos (content.size e amount.size)​

O tamanho do texto e o tamanho do valor são escolhidos separadamente. md é o padrão; sm é a escala compacta (a mesma dos itens filhos). A tag do valor acompanha o amount.size (md → Medium, sm → Small).

<List>
  <TransactionListReadOnly
    content={{ title: 'Title', description: 'md / md' }}
    amount={{ value: 'R$ 0,00' }}
  />
  <TransactionListReadOnly
    content={{ title: 'Title', description: 'sm / md', size: 'sm' }}
    amount={{ value: 'R$ 0,00' }}
  />
  <TransactionListReadOnly
    content={{ title: 'Title', description: 'md / sm' }}
    amount={{ value: 'R$ 0,00', size: 'sm' }}
  />
</List>

Tipos de valor (amount.type)​

<List>
  <TransactionListReadOnly
    content={{ title: 'Default' }}
    amount={{ value: 'R$ 100,00' }}
  />
  <TransactionListReadOnly
    content={{ title: 'Positive' }}
    amount={{ value: 'R$ 100,00', type: 'positive' }}
  />
  <TransactionListReadOnly
    content={{ title: 'Negative' }}
    amount={{ value: 'R$ 100,00', type: 'negative' }}
  />
  <TransactionListReadOnly
    content={{ title: 'Strikethrough' }}
    amount={{
      value: 'Grátis',
      strikethroughValue: '3,99%',
      type: 'strikethrough',
    }}
  />
  <TransactionListReadOnly
    content={{ title: 'Strikethrough Neutral' }}
    amount={{
      value: 'R$ 2,00',
      strikethroughValue: 'R$ 3,99',
      type: 'strikethrough-neutral',
    }}
  />
</List>
  • strikethrough: o valor mudou a favor do cliente — original riscado (Interface/Dark/Up) e atual em verde (Status/Positive/Deep), na mesma linha.
  • strikethrough-neutral: o valor só mudou — atual em Interface/Dark/Deep.

Textos longos​

  • Os textos do conteúdo (content) quebram em até duas linhas e depois são cortados com reticências. O corte é só visual: leitores de tela leem o texto completo.
  • A informação do valor (amount.info) também quebra em até duas linhas e depois é cortada com reticências.
  • A tag (amount.tag) fica em uma linha; rótulos longos são truncados com reticências, e o rótulo completo continua disponível para leitores de tela e como dica (title).

Cor do ícone (iconColor)​

A cor do ícone à esquerda vem de um conjunto fechado:

ValorTokenQuando usar
default (padrão)Interface/Dark/UpLinha sobre fundo branco
on-colorInterface/Dark/DownLinha sobre fundo colorido (ex.: heróis em Status/Warning/Up, Status/Negative/Up)
highlightBrand/Primary/DownMais ênfase

Desabilitado sempre força Interface/Light/Deep, qualquer que seja a escolha — não é uma opção. O ícone herda a cor do componente: passe ícones sem cor própria (ex.: <PlaceholderOutline size={24} />, sem color).

Estados​

<List>
  <TransactionListReadOnly
    content={{ title: 'Desabilitado', description: 'Tipo inativo nos blocos' }}
    amount={{ value: 'R$ 0,00', tag: { label: 'Label' } }}
    icon={<PlaceholderOutline size={24} />}
    disabled
  />
  <TransactionListReadOnly
    content={{ title: 'Carregando' }}
    amount={{ value: 'R$ 0,00' }}
    icon={<PlaceholderOutline size={24} />}
    loading
  />
</List>

O desabilitado vem do tipo Inactive de conteúdo e valor (tag neutra), nunca de opacidade forçada. content.status e amount.type são ignorados enquanto a linha está desabilitada.

Divisor​

O divisor (recuo de 16px, mix-blend-mode: multiply) aparece por padrão. Use showDivider={false} no último item quando o container já separa o grupo.

Densidade (density)​

density="compact" reduz o padding vertical da linha para 8 (Spacing/Xxs) — 16 no default. O padding horizontal, o espaço entre os elementos e o divisor não mudam; o esqueleto de carregamento acompanha.

Altura da linha por tamanho (conteúdo + valor com legenda, etiqueta e informação extra): md 100 / compact 84; sm 94 / compact 78; carregando 73 / compact 57.

Acessibilidade​

  • Elemento <div> sem papel interativo; aria-disabled quando desabilitado e aria-busy durante o carregamento.
  • O corte de textos longos é só visual: leitores de tela leem o conteúdo e o rótulo da tag completos.

Quando usar​

  • Valor monetário como peça principal, sem navegação, expansão ou seleção.
  • Com navegação → TransactionListAction. Com seleção → TransactionListSelectable. Com detalhes na própria lista → TransactionListExpandable.
