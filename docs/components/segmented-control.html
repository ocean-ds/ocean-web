Segmented Control

O Segmented Control é um controle com exatamente 2 opções, uma sempre selecionada, que troca o escopo ou a visão do mesmo conteúdo (ex.: Loja | Rede, Lista | Calendário). Ele renderiza só o controle: a tela guarda a opção selecionada e atualiza o conteúdo.

Importação​

import { SegmentedControl } from '@useblu/ocean-react';
import type {
  SegmentedControlProps,
  SegmentedControlOption,
  SegmentedControlIndex,
  SegmentedControlBackground,
} from '@useblu/ocean-react';

Uso básico​

import { useState } from 'react';
import { SegmentedControl } from '@useblu/ocean-react';
import { CalendarOutline, ViewListOutline } from '@useblu/ocean-icons-react';

function ScheduleView() {
  const [selected, setSelected] = useState<0 | 1>(0);

  return (
    <>
      <SegmentedControl
        aria-label="Visão"
        options={[
          { label: 'Lista', icon: <ViewListOutline /> },
          { label: 'Calendário', icon: <CalendarOutline />, count: 3 },
        ]}
        selectedIndex={selected}
        onChange={setSelected}
      />
      {selected === 0 ? <ScheduleList /> : <ScheduleCalendar />}
    </>
  );
}

Fundo branco​

Sobre superfícies color-interface-light-up (cards, heros), o fundo padrão do controle some. Use background="white":

<SegmentedControl
  aria-label="Escopo"
  options={[{ label: 'Loja' }, { label: 'Rede' }]}
  selectedIndex={selected}
  onChange={setSelected}
  background="white"
/>

Desabilitado​

disabled desabilita o controle inteiro: a seleção continua visível em cinza, nenhuma opção troca e onChange não é chamado. Use quando a troca existe mas está indisponível no momento; quando ela não faz sentido para a pessoa (ex.: loja sem rede), não renderize o controle.

<SegmentedControl
  aria-label="Escopo"
  options={[{ label: 'Loja' }, { label: 'Rede' }]}
  selectedIndex={0}
  onChange={setSelected}
  disabled
/>

Quando usar​

Use quando a tela mostra o mesmo conteúdo em 2 escopos ou 2 visões e a pessoa alterna entre eles: uma loja ou a rede inteira, lista ou calendário.

Quando NÃO usar​

SituaçãoUse no lugar
Seções com conteúdo próprioTab
Filtrar uma mesma lista (Todos, Pendentes, Pagos…)Filter Bar (Chips)
Ligar ou desligar uma configuraçãoSwitch
Uma escolha dentro de um formulárioRadio
Mais de 2 opçõesTab ou Filter Bar (Chips)
Troca que não faz sentido para a pessoaNão mostre o controle (não existe estado carregando)

API​

Props​

PropTipoPadrãoDescrição
options[SegmentedControlOption, SegmentedControlOption]-As duas opções, em ordem. Cada uma tem label: string, icon?: ReactNode e count?: number. Só as 2 primeiras são desenhadas; itens a mais são ignorados.
selectedIndex0 | 1-Índice da opção selecionada. Qualquer outro valor seleciona a primeira opção.
onChange(index: 0 | 1) => void-Chamado com o índice da opção escolhida por clique ou seta. Não é chamado no clique da opção já selecionada.
background'default' | 'white''default'Fundo do controle: default (color-interface-light-up), para telas brancas; white (color-interface-light-pure), para superfícies light up como cards e heros.
disabledbooleanfalseDesabilita o controle inteiro: opções viram botões disabled (fora da ordem de tabulação), o grupo recebe aria-disabled="true" e onChange não é chamado.
aria-labelstring-Nome do controle para leitores de tela, como "Escopo" ou "Visão".
classNamestring-Classe extra no controle.
refRef<HTMLDivElement>-Encaminhado para o elemento do controle (role="radiogroup"). Os demais atributos de div também vão para ele.

SegmentedControlOption​

CampoTipoPadrãoDescrição
labelstring-Texto da opção. Uma linha só; cortado com "…" quando não cabe.
iconReactNode-Ícone de 16px antes do texto, na cor do texto. Passe sem cor nem tamanho.
countnumber-Contador (Badge pequeno) depois do texto: Primary Inverse na opção selecionada, Primary na outra, Neutral quando desabilitado. Acima de 99 mostra 99+.

Comportamento​

  • Estados: o estado é do controle inteiro, sem borda. Padrão: fundo color-interface-light-up (ou color-interface-light-pure com background="white"), seleção cheia em color-brand-primary-pure, texto e ícone brancos na opção selecionada e color-brand-primary-pure na outra. Hover e foco de teclado mudam só o fundo do controle para color-interface-light-down, nos dois fundos; o foco de teclado tem a mesma aparência do hover, sem contorno.
  • Desabilitado: fundo do controle igual ao do background, seleção color-interface-light-down, textos e ícones color-interface-dark-up, contadores Neutral; sem hover.
  • Sem carregando: quem carrega é o conteúdo abaixo do controle. Se a troca não faz sentido para a pessoa, a tela não mostra o controle.
  • Transição: na troca de opção, o fundo de seleção desliza da opção anterior até a nova (posição e largura juntas) em 300ms, cubic-bezier(0.65, 0, 0.35, 1), sem overshoot. O texto, o ícone e o contador trocam de cor junto com o fundo de seleção, na mesma duração e curva. A cor de fundo do controle (hover e foco) muda em 150ms. Com prefers-reduced-motion: reduce, a troca é imediata.
  • Largura: o controle tem a largura das duas opções (não estica). Altura total de 40px; cada opção tem 32px.
  • Texto: sempre em uma linha. Se o controle não couber no container, ele para na largura do container e o texto é cortado com "…"; o leitor de tela continua lendo o texto inteiro.

Acessibilidade​

TeclaAção
TabLeva o foco para a opção selecionada e, depois, para fora
→ ← ↑ ↓Vão para a outra opção e a selecionam

Desabilitado, as opções saem da ordem de tabulação e nenhuma tecla troca a seleção.

  • O controle tem role="radiogroup" com o aria-label; cada opção é um <button role="radio"> com aria-checked.
  • Só a opção selecionada entra na ordem de tabulação (tabIndex=0); a outra fica com -1 (roving tabindex).
  • O contador é lido como parte do nome da opção.
  • Desabilitado, o grupo tem aria-disabled="true" e cada opção é um botão disabled.
